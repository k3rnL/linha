    Configuration reference¶

    Choose the configuration surface you are working with. Application backend fields and operator deployment fields have separate complete references.

    Surface Canonical reference
    Declare a worker/backend BackendSpec and ensure
    Set Spark main class, JAR, resources and scaling SparkSettings
    Configure environment, files and scheduling Pod fragments
    Select result storage, size, retention and paths ResultPolicy
    Access application inputs/shared files Workload storage
    Submit a request, retry or deadline SubmitRequest
    Configure the Linha deployment Helm values

    The model index includes all named public models and nested configuration structures. Tables list field types, requiredness, defaults, bounds and interactions; JSON/Scala example tabs share those definitions.

    Helm deployment settings¶

    Every chart option is listed in Helm values. S3 destination and membership models describe structured operator policy. Use deployment procedures to install.

    Spark settings¶

    See SparkSettings, including application, drivers, executors, UI, and Pod fragments.

    Results and request policy¶

    ResultPolicy controls output storage, size and retention. SubmitRequest controls retry/deadline; job state semantics describe acceptance, execution and cancellation. These are different model surfaces.

    Result path templates¶

    See PathTemplate and the complete placeholder/validation rules.

    Standalone server environment¶

    Server environment lists every Linha server variable, standalone default and Helm equivalent. Worker-injected variables are in the worker reference.
