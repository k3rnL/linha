    Helm values¶

    Operator settings passed through a values file. Backend declarations use the separate backend reference. Default values below come from the checked-in chart; nested item fields have no default unless stated. Native Kubernetes/monitoring objects retain their upstream validation.

    Field Type Default Meaning and constraints
    replicaCount integer 2 API replicas sharing the database; default 2. External database/storage HA is operator-managed.
    image object Object; see nested fields Server image selection. Keep chart, image and SDK versions compatible.
    image.repository string "ghcr.io/k3rnl/linha/server" Server image repository.
    image.tag string "0.1.4" Server image version; use the chart release version.
    image.pullPolicy string "IfNotPresent" Kubernetes image pull policy.
    imagePullSecrets array [] Server image pull Secret references, also permitted worker defaults.
    database object Object; see nested fields Database connection configuration; database is provisioned externally.
    database.postgres object Object; see nested fields PostgreSQL connection and caller-managed credential Secret.
    database.postgres.host string "postgres" PostgreSQL DNS/IP hostname. Minimum length 1.
    database.postgres.port integer 5432 TCP port. Minimum 1. Maximum 65535.
    database.postgres.database string "linha" Existing PostgreSQL database name. Minimum length 1.
    database.postgres.sslMode string "verify-full" TLS mode passed to pgx; verification defaults to verify-full. Values: disable, allow, prefer, require, verify-ca, verify-full.
    database.postgres.sslRootCert string "" Optional mounted CA certificate path.
    database.postgres.secretRef string "linha-postgres" Existing Secret containing database credentials. Minimum length 1.
    database.postgres.usernameKey string "username" Username key in that Secret. Minimum length 1.
    database.postgres.passwordKey string "password" Password key in that Secret. Minimum length 1.
    security object Object; see nested fields Independent application API, browser and worker authentication settings.
    security.enabled boolean true Master authentication switch; false disables API/worker security and uses one shared owner.
    security.api object Object; see nested fields Public application API identity configuration.
    security.api.enabled boolean true Validate API JWTs when master security is enabled.
    security.api.jwt object Object; see nested fields JWT discovery, signature and audience validation settings.
    security.api.jwt.issuer string "" Required issuer when API authentication is enabled.
    security.api.jwt.audience string "linha" Required intended API token audience. Minimum length 1.
    security.api.jwt.tls object Object; see nested fields TLS trust settings for API identity discovery and signing-key requests.
    security.api.jwt.tls.insecureSkipVerify boolean false Skip API provider certificate/hostname verification only; JWT checks remain.
    security.oidc object Object; see nested fields Browser administrator OIDC login; separate from application API JWTs.
    security.oidc.enabled boolean true Enable OIDC; a secured enabled UI requires it.
    security.oidc.issuer string "" Required browser issuer for secured UI; inherited by membership rules.
    security.oidc.tls object Object; see nested fields TLS trust settings for browser identity operations.
    security.oidc.tls.insecureSkipVerify boolean false Skip browser provider certificate/hostname verification only; browser trust is separate.
    security.admin object Object; see nested fields Viewer/operator membership rules; see membership models in the storage/provider reference.
    security.admin.viewer object Object; see nested fields Viewer membership; rules inherit the browser issuer.
    security.admin.viewer.subjects array [] Explicit subject membership rules.
    security.admin.viewer.subjects[].issuer string Omitted Optional; if supplied it must equal the browser issuer.
    security.admin.viewer.subjects[].subject string Omitted Required nonempty token subject. Minimum length 1.
    security.admin.viewer.claims array [] Membership by matching a nested claim.
    security.admin.viewer.claims[].issuer string Omitted Optional; if supplied it must equal the browser issuer.
    security.admin.viewer.claims[].path array Omitted 1–8 nested claim keys; each nonempty, at most 128 bytes, not proto.
    security.admin.viewer.claims[].values array Omitted Nonempty list of allowed string values.
    security.admin.operator object Object; see nested fields Operator membership; rules inherit the browser issuer.
    security.admin.operator.subjects array [] Explicit subject membership rules.
    security.admin.operator.subjects[].issuer string Omitted Optional; if supplied it must equal the browser issuer.
    security.admin.operator.subjects[].subject string Omitted Required nonempty token subject. Minimum length 1.
    security.admin.operator.claims array [] Membership by matching a nested claim.
    security.admin.operator.claims[].issuer string Omitted Optional; if supplied it must equal the browser issuer.
    security.admin.operator.claims[].path array Omitted 1–8 nested claim keys; each nonempty, at most 128 bytes, not proto.
    security.admin.operator.claims[].values array Omitted Nonempty list of allowed string values.
    rbac object Object; see nested fields Worker/resource permission configuration.
    rbac.namespaceOnly boolean true Namespaced management with projected-token verification; false adds cluster-scoped TokenReview permission.
    allowedImages array [] Allowed worker, init-container and sidecar image repository prefixes. A nonempty allow-list is required for managed server startup.
    local object Object; see nested fields Optional shared-filesystem result provider.
    local.enabled boolean false Configure local result storage on servers.
    local.root string "/var/lib/linha/results" Persistent shared root; client result root must match exactly.
    local.existingClaim string "" Existing server PVC; drivers/executors still need matching shared mounts.
    s3 object Object; see nested fields Server S3 destination configuration.
    s3.enabled boolean false Load named destinations from the selected Secret.
    s3.secretRef string "linha-s3" Existing Secret with destination JSON; AWS credentials use the server default credential chain.
    s3.destinationsKey string "destinations" Secret key containing the destination-name → S3Config JSON object.
    workerVolumes array [] Legacy administrator volumes snapshotted into new context templates; prefer explicit templates.
    workerMounts array [] Legacy worker mounts; PVC mounts also flow to executor templates.
    workerPodTemplates object Object; see nested fields Administrator Pod defaults merged with caller overrides for a new context.
    workerPodTemplates.driverPodTemplate object {} Native Pod fragment; see the backend Pod-template reference for merge/protected-field rules.
    workerPodTemplates.driverPodTemplate.metadata object Omitted Application labels/annotations only.
    workerPodTemplates.driverPodTemplate.metadata.labels object Omitted String label map; runtime prefixes are protected.
    workerPodTemplates.driverPodTemplate.metadata.annotations object Omitted String annotation map; runtime prefixes are protected.
    workerPodTemplates.driverPodTemplate.spec object Omitted Kubernetes v1 PodSpec subject to Linha/Spark restrictions.
    workerPodTemplates.executorPodTemplate object {} Native Pod fragment; see the backend Pod-template reference for merge/protected-field rules.
    workerPodTemplates.executorPodTemplate.metadata object Omitted Application labels/annotations only.
    workerPodTemplates.executorPodTemplate.metadata.labels object Omitted String label map; runtime prefixes are protected.
    workerPodTemplates.executorPodTemplate.metadata.annotations object Omitted String annotation map; runtime prefixes are protected.
    workerPodTemplates.executorPodTemplate.spec object Omitted Kubernetes v1 PodSpec subject to Linha/Spark restrictions.
    registrySecrets object Object; see nested fields Registry credential access policy for per-context private image resolution.
    registrySecrets.allowedNames array [] Permitted Secret names; each gets namespaced get permission for primary image digest resolution.
    results object Object; see nested fields Server result staging and physical-cleanup policy, not the per-backend ResultPolicy.
    results.cleanup object Object; see nested fields Physical deletion policy for tracked allocations only.
    results.cleanup.enabled boolean false Opt in to eligible terminal/expired allocation deletion after writer expiry and grace; job history remains.
    results.maxStagingBytes integer 5368709120 Concurrent server staging reservation budget in bytes; default 5 GiB. Minimum 1.
    extraEnv array [] Additional native Kubernetes EnvVar entries for server Pods.
    extraVolumes array [] Additional native Kubernetes volumes for server Pods.
    extraVolumeMounts array [] Additional native Kubernetes volume mounts for server containers.
    resources object Object; see nested fields Server Pod requests and limits, separate from Spark worker resources.
    resources.requests object Object; see nested fields Native server container resource requests limit.
    resources.requests.cpu string "100m" Native server container resource cpu request.
    resources.requests.memory string "128Mi" Native server container resource memory request.
    resources.limits object Object; see nested fields Native server container resource limits limit.
    resources.limits.memory string "512Mi" Native server container resource memory limit.
    podAnnotations object {} Server Pod annotation map.
    nodeSelector object {} Server Pod node-label selector map.
    tolerations array [] Server Pod Kubernetes tolerations.
    ui object Object; see nested fields Embedded administrator console and browser sessions.
    ui.enabled boolean false Register UI, browser login and administrator routes.
    ui.publicURL string "" Required absolute HTTP(S) URL ending exactly /ui/, without credentials, query or fragment.
    ui.ingress object Object; see nested fields Same-origin UI/admin Ingress; does not expose the public job API or Spark UI.
    ui.ingress.enabled boolean false Render Ingress for /ui and /v1/admin.
    ui.ingress.className string "" Optional IngressClass name. Maximum length 253.
    ui.ingress.annotations object {} Ingress annotations map.
    ui.ingress.tls object Object; see nested fields Ingress TLS certificate selection.
    ui.ingress.tls.enabled boolean false Enable TLS for the publicURL host.
    ui.ingress.tls.secretName string "" Existing TLS Secret for the host. Maximum length 253.
    ui.sessionSeconds integer 3600 Absolute browser session lifetime, 60–86400 seconds. Provider refresh renews authentication within this limit; without refresh, token expiry can end access sooner. Minimum 60. Maximum 86400.
    ui.grafanaURL string "" Optional absolute Grafana link shown in the console.
    ui.oidc object Object; see nested fields Browser client configuration, independent of application OAuth credentials.
    ui.oidc.clientId string "" Required browser client ID/audience for secured UI.
    ui.oidc.scopes array ["openid","profile","email"] Replaces defaults; nonempty unique valid scope strings, including openid. Request groups when needed.
    ui.oidc.secretRef string "" Optional existing browser confidential-client Secret.
    ui.oidc.clientSecretKey string "client-secret" Key holding browser client secret.
    metrics object Object; see nested fields Prometheus endpoint, context dimensions and optional monitoring resources.
    metrics.enabled boolean true Register /metrics.
    metrics.maxContexts integer 100 Lifetime cap on named context metric dimensions; 0–10000. Minimum 0. Maximum 10000.
    metrics.cluster string "" Cluster label used by monitoring resources.
    metrics.contextAliases array [] Persistent owner/logical-name alias overrides, applied before enrollment.
    metrics.contextAliases[].owner string Omitted Application owner.
    metrics.contextAliases[].name string Omitted Logical context name.
    metrics.contextAliases[].alias string Omitted Bounded explicit metric alias.
    metrics.serviceMonitor object Object; see nested fields Optional Prometheus Operator ServiceMonitor; CRD must already exist.
    metrics.serviceMonitor.enabled boolean false Render ServiceMonitor; no operator/CRD installation.
    metrics.serviceMonitor.labels object {} Labels used by the Prometheus ServiceMonitor selector.
    metrics.serviceMonitor.interval string "30s" Prometheus scrape interval.
    metrics.serviceMonitor.scrapeTimeout string "10s" Prometheus scrape timeout.
    metrics.serviceMonitor.scheme string "http" Scrape HTTP or HTTPS. Values: http, https.
    metrics.serviceMonitor.sampleLimit integer 100000 Maximum samples accepted per scrape. Minimum 1. Maximum 10000000.
    metrics.serviceMonitor.relabelings array [] Prometheus target relabeling configurations.
    metrics.serviceMonitor.metricRelabelings array [] Prometheus metric relabeling configurations.
    metrics.serviceMonitor.tlsConfig object {} Native ServiceMonitor TLS client configuration.
    metrics.serviceMonitor.authorization object {} Native ServiceMonitor scrape authorization.
    metrics.grafanaDashboard object Object; see nested fields Optional Grafana Operator dashboard; CRD must already exist.
    metrics.grafanaDashboard.enabled boolean false Render dashboard resource; no Grafana/CRD installation.
    metrics.grafanaDashboard.labels object {} Dashboard resource labels.
    metrics.grafanaDashboard.instanceSelector object {} Selector for Grafana instances receiving this dashboard.
    metrics.grafanaDashboard.folder string "Linha" Grafana folder name.
    metrics.grafanaDashboard.datasourceUID string "" Grafana Prometheus datasource UID.
    metrics.grafanaDashboard.allowCrossNamespaceImport boolean false Allow Grafana Operator cross-namespace dashboard import.
    metrics.grafanaDashboard.resyncPeriod string "10m" Grafana Operator resync interval.

    See environment equivalents, S3 destinations and membership, deployment procedures and monitoring. The removed existingSecret, deploymentMode, top-level oidc and security.oidc.audience fields are not supported.
