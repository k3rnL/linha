    Operational observations¶

    Operational models are read-only administrator observations across owners. They combine durable records with time-stamped engine/server observations. Check available, stale and observedAt before interpreting live resources or links. Observation does not attach a client or start an engine.

    Page envelopes contain items and an opaque nextCursor; an omitted cursor ends the listing. Copy cursors unchanged. Overview counts are independent of page size.

    Field paths below are relative to their containing model; output fields have no caller default.

    OperationalContext¶

    Administrator output combining Context with queue and client/worker counts.

    Field Type Presence / default Meaning and constraints
    id string Present; no caller default Opaque server/resource identity; preserve it verbatim.
    name string Present; no caller default Logical name within its containing model.
    spec BackendSpec Present; no caller default Effective normalized backend configuration; follow BackendSpec.
    state string Present; no caller default Current persisted or observed lifecycle state; see the model notes.
    condition string Optional output; no caller default Optional diagnostic condition explaining provisioning or observation state.
    createdAt string (date-time) Present; no caller default Server-recorded creation instant (RFC 3339).
    version string Present; no caller default SHA-256 of effective configuration
    clientLease ClientLease Optional output; no caller default Lease returned by ensure/attach. A plain GET neither attaches nor renews it.
    owner string Optional output; no caller default Authenticated application owner; supplied by the server, not application request JSON.
    metricContext string Optional output; no caller default Bounded metric alias for this owner/logical context.
    observedAt string (date-time) Optional output; no caller default Time of the latest observation or coherent summary (RFC 3339).
    liveClients integer Optional output; no caller default Count of live client leases.
    queuedJobs integer Optional output; no caller default Queued demand, including retrying jobs where noted by the summary.
    runningJobs integer Optional output; no caller default Count of running work, including cancellation in progress where the read model groups it.
    readyWorkers integer Optional output; no caller default Count of ready/live registered workers.
    desiredInstances integer Optional output; no caller default Controller desired driver/instance count.

    OperationalClient¶

    Administrator output describing a client attachment or the last recorded lease.

    Field Type Presence / default Meaning and constraints
    id string Present; no caller default Opaque server/resource identity; preserve it verbatim.
    clientId string Present; no caller default Application process identifier, at most 128 bytes. Omission generates an ID; the SDK reuses one per client.
    expiresAt string (date-time) Optional output; no caller default Server-recorded expiry instant (RFC 3339); check before using retained access.
    lastRenewedAt string (date-time) Optional output; no caller default Last recorded client lease renewal time (RFC 3339).
    state string Present; no caller default Current persisted or observed lifecycle state; see the model notes. Values: active, expired, released.
    hostname string Optional output; no caller default Optional client-reported hostname (at most 253 UTF-8 bytes, no whitespace/control characters). Display metadata only; never identity or authorization. Maximum length: 253.

    EngineObservation¶

    Optional adapter observation in OperationalInstance.detail.

    Field Type Presence / default Meaning and constraints
    application string Optional output; no caller default Spark application identity or settings, according to the model.
    applicationState string Optional output; no caller default Latest SparkApplication state reported by the adapter.
    driverPod string Optional output; no caller default Observed Spark driver Pod name.
    driverPhase string Optional output; no caller default Latest Kubernetes Pod phase for the driver.
    uiAddress string Optional output; no caller default Observed driver UI address when available.
    uiService string Optional output; no caller default Observed Spark UI Service name.
    condition string Optional output; no caller default Optional diagnostic condition explaining provisioning or observation state.
    uiPort integer Optional output; no caller default Observed Spark UI TCP port.
    available boolean Optional output; no caller default Whether current engine observation is available.
    executorStates map of integer Optional output; no caller default Dynamic map of observed executor state to count.
    resources map of number Optional output; no caller default Dynamic map of normalized observed resource measurements, not configurable resource requests.
    links array of object (fields) Optional output; no caller default Observed engine links with display names and URLs; unavailable/stale data must not imply a live UI.

    OperationalInstance¶

    Administrator output describing a managed engine instance and observation freshness.

    Field Type Presence / default Meaning and constraints
    id string Present; no caller default Opaque server/resource identity; preserve it verbatim.
    contextId string Optional output; no caller default Opaque immutable context-version ID, not the logical context name.
    incarnation string Optional output; no caller default Managed worker incarnation; prevents a replacement process from impersonating an old attempt.
    resourceKind string Optional output; no caller default Adapter-managed resource kind, such as sparkapplication or pod.
    resourceUid string Optional output; no caller default Kubernetes resource UID used to reject replacement/deletion identity races.
    state string Present; no caller default Current persisted or observed lifecycle state; see the model notes.
    createdAt string (date-time) Optional output; no caller default Server-recorded creation instant (RFC 3339).
    observedAt string (date-time) Optional output; no caller default Time of the latest observation or coherent summary (RFC 3339).
    available boolean Present; no caller default Whether current engine observation is available.
    stale boolean Present; no caller default True when the recorded engine observation is too old to represent current state.
    detail EngineObservation Optional output; no caller default Optional engine/server observation details; adapter-specific object.

    OperationalWorker¶

    Administrator output describing a registered worker and occupied request slots.

    Field Type Presence / default Meaning and constraints
    id string Present; no caller default Opaque server/resource identity; preserve it verbatim.
    contextId string Present; no caller default Opaque immutable context-version ID, not the logical context name.
    incarnation string Present; no caller default Managed worker incarnation; prevents a replacement process from impersonating an old attempt.
    capacity integer Present; no caller default Concurrent request slots; worker registration accepts 1–128, Spark backend concurrency 1–32. Minimum: 1. Maximum: 128.
    capabilities array of Capability Present; no caller default Nonempty list (at most 256) of unique handler/version/result contracts.
    draining boolean Optional output; no caller default Whether the worker has stopped accepting new assignments.
    heartbeatAt string (date-time) Optional output; no caller default Last recorded worker/server heartbeat instant (RFC 3339).
    state string Optional output; no caller default Current persisted or observed lifecycle state; see the model notes. Values: ready, draining, stale.
    occupiedSlots integer Optional output; no caller default Currently occupied worker request slots.

    AdminOverview¶

    Output of GET /v1/admin/overview, measured coherently across owners.

    Coherent read-only summary over all owners. Counts are independent of pagination. queuedJobs includes retryingJobs; terminal outcomes use updatedAt within since..observedAt. Server counts use the latest heartbeat per pod in that window.

    Field Type Presence / default Meaning and constraints
    runningJobs integer (int64) Present; no caller default Count of running work, including cancellation in progress where the read model groups it. Minimum: 0.
    queuedJobs integer (int64) Present; no caller default Queued demand, including retrying jobs where noted by the summary. Minimum: 0.
    retryingJobs integer (int64) Present; no caller default Retrying subset of queued demand, including work in backoff. Minimum: 0.
    cancellingJobs integer (int64) Present; no caller default Work with committed cancellation intent that has not yet become terminal. Minimum: 0.
    succeededJobs24h integer (int64) Present; no caller default Succeeded jobs updated within the summary time window. Minimum: 0.
    failedJobs24h integer (int64) Present; no caller default Failed jobs updated within the summary time window. Minimum: 0.
    cancelledJobs24h integer (int64) Present; no caller default Cancelled jobs updated within the summary time window. Minimum: 0.
    activeContexts integer (int64) Present; no caller default Active context-version count in the coherent summary. Minimum: 0.
    liveClients integer (int64) Present; no caller default Count of live client leases. Minimum: 0.
    readyWorkers integer (int64) Present; no caller default Count of ready/live registered workers. Minimum: 0.
    workerSlots integer (int64) Present; no caller default Total available configured worker request capacity in the summary. Minimum: 0.
    occupiedSlots integer (int64) Present; no caller default Currently occupied worker request slots. Minimum: 0.
    serversReady integer (int64) Present; no caller default Ready server count, deduplicated by Pod. Minimum: 0.
    serversUnready integer (int64) Present; no caller default Unready server count, deduplicated by Pod. Minimum: 0.
    serversStale integer (int64) Present; no caller default Server count whose latest Pod heartbeat is stale. Minimum: 0.
    observedAt string (date-time) Present; no caller default Time of the latest observation or coherent summary (RFC 3339).
    since string (date-time) Present; no caller default Start of the terminal-outcome summary window (RFC 3339).
    oldestQueuedSeconds number Present; no caller default Age in seconds of the oldest queued/retrying request, or zero. Minimum: 0.
    meanProcessingSeconds24h number Present; no caller default Mean finished execution-attempt duration in the last 24 hours; excludes initial queue wait and counts retries separately. Null if no durations exist. Minimum: 0.
    activeContextDetails array of OverviewContext Present; no caller default Bounded active-context summaries; counts above remain independent of list size. Maximum items: 5.
    recentFailures array of OverviewFailure Present; no caller default Bounded recent failure summaries across owners. Maximum items: 5.

    OverviewFailure¶

    Recent failed-job summary in AdminOverview.recentFailures.

    Field Type Presence / default Meaning and constraints
    id string Present; no caller default Opaque server/resource identity; preserve it verbatim.
    contextId string Present; no caller default Opaque immutable context-version ID, not the logical context name.
    contextName string Present; no caller default Stable logical context name.
    owner string Present; no caller default Authenticated application owner; supplied by the server, not application request JSON.
    handler string Present; no caller default Stable registered handler name; executable code is installed in the worker image.
    message string Present; no caller default Human-readable detail; progress messages are at most 4096 bytes.
    updatedAt string (date-time) Present; no caller default Last durable job state/update instant (RFC 3339).
