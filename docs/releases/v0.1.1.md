# Linha 0.1.1

Linha 0.1.1 adds configurable identity-provider HTTPS verification and simplifies
administrator membership rules.

## Changes

- `security.oidc.tls.insecureSkipVerify` and its environment equivalent default
  to false and apply only to identity discovery, signing keys and browser token
  exchange. Signature, issuer, audience, expiry, nonce and membership checks remain.
- Viewer/operator rules inherit the configured browser issuer. Repeating it is
  optional; a conflicting issuer is rejected.
- CI regenerates temporary fixture output instead of relying on cached test
  success, and pins Maven 3.9.9 for deterministic Central bundles.

## Upgrade

Update the server image and chart together to 0.1.1. No database migration or
worker protocol change is required. Certificate bypass is optional; trusting the
provider CA keeps TLS verification enabled. The server's setting does not change
browser certificate trust.

This is a historical release. Current API/browser authentication fields differ;
use the documentation captured with the version you deploy.

## Artifacts and verification

Images are `ghcr.io/k3rnl/linha/server:0.1.1` and
`ghcr.io/k3rnl/linha/spark-example:0.1.1`. JVM artifacts use `com.k3rnl`, version
0.1.1, with sources, API documentation and signatures. The release includes the
Helm chart and checksum.

Validation covered Go/PostgreSQL tests and race checks, browser sessions,
Java 17 JVM builds, chart configuration, formatting, release preparation and
specification validation. See the
[release comparison](https://github.com/k3rnL/linha/compare/v0.1.0...v0.1.1).
