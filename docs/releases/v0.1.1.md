# Linha 0.1.1

Linha 0.1.1 adds configurable OIDC HTTPS verification and simplifies administrator membership configuration.

## Changes

- Add `security.oidc.tls.insecureSkipVerify` (default `false`) and `LINHA_OIDC_TLS_INSECURE_SKIP_VERIFY`. The setting covers discovery, signing-key retrieval/refresh, and browser OAuth token exchange.
- Keep JWT signature, issuer, audience, expiry, browser nonce, and administrator membership validation enforced. Kubernetes worker authentication and unrelated TLS clients keep their existing verification.
- Viewer/operator subject and claim rules now inherit `security.oidc.issuer`. Repeated rule issuers are optional; matching legacy values remain valid and conflicting values are rejected.
- Document provider CA mounting, browser trust boundaries, and migration. Archive both completed OpenSpec changes and sync their canonical requirements.
- Include the fixture-cache CI correction introduced after v0.1.0 and support Helm 3/4 schema diagnostic formats in chart tests.

## Upgrade

Upgrade the server image and Helm chart together to `0.1.1`. No database migration or client/worker protocol change is required; existing SDKs and business worker images remain compatible. The SDKs are also published at `0.1.1` for consistent coordinates.

```yaml
image:
  tag: 0.1.1
security:
  oidc:
    tls:
      insecureSkipVerify: true
  admin:
    viewer:
      claims:
        - path: [roles]
          values: [linha-viewer]
    operator:
      subjects:
        - subject: your-admin-subject
```

Retain your existing global issuer/audience and other deployment settings. Certificate bypass is optional and disabled by default. Trusting the identity provider CA is preferable for production; bypassing verification allows provider impersonation. This server setting does not change certificate trust in browsers.
