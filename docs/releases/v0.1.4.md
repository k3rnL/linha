# Linha 0.1.4

Linha 0.1.4 makes configuration and SDK information easier to find, with a
categorized reference and a searchable index of public models and types.

## Changes

- Complete field references for backend declarations, Spark applications,
  driver/executor resources, Pod templates and result policies, including defaults,
  bounds and interactions.
- References for requests, results, application storage, HTTP protocols, Scala/JVM
  SDK APIs, Helm values and server environment variables.
- Shared JSON model definitions, equivalent JSON/Scala example tabs and direct
  links from guides to individual models and fields. Existing entry URLs and useful
  anchors remain available.
- Driver JVM system-property and Log4j configuration examples, with links to the
  upstream SparkApplication API and guide.
- Automated reference coverage checks for public models and nested fields,
  deployment settings and SDK families.
- Public OCI Helm chart distribution at `oci://ghcr.io/k3rnl/charts/linha`, with
  an anonymous-pull check and chart-only recovery for existing releases.

Start at the [reference index](../reference/index.md) or
[Spark settings](../reference/backend/spark.md).

## Upgrade

Runtime behavior, public API fields and the database schema are unchanged from
0.1.3. There is no new configuration or database migration for this update.
Applications using 0.1.3 can use the expanded reference without rebuilding their
clients or workers. Upgrades from earlier versions must also follow the
[0.1.3 upgrade instructions](v0.1.3.md#upgrade).

Published documentation snapshots remain frozen. Select 0.1.4 or `latest` to read
the new reference.

## Artifacts and validation

Matching 0.1.4 artifacts include `ghcr.io/k3rnl/linha/server:0.1.4`,
`ghcr.io/k3rnl/linha/spark-example:0.1.4`, and the `com.k3rnl` JVM parent plus
protocol, client, worker, Spark and Hadoop SDK modules. The Helm chart is available
through OCI and as a GitHub release archive with its checksum.

Documentation checks cover model/field presence, navigation and links, frozen
versions and public content. The release workflow also runs the existing runtime,
restart and packaging checks before publishing artifacts. Reference coverage
checks establish structural presence; descriptions and defaults still require
source review.

See the [release comparison](https://github.com/k3rnL/linha/compare/v0.1.3...v0.1.4).
